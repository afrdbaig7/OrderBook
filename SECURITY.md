# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |

## Reporting a Vulnerability

We take the security of this project seriously. If you discover a security vulnerability, please do **not** open a public issue.

Instead, please report it privately:

1. Send an email to the maintainer at `mohammedafreedbaig47@gmail.com`.
2. Provide a detailed description of the vulnerability, including steps to reproduce, affected components, and potential impact.
3. You will receive an acknowledgment within 48 hours.
4. Please give the maintainers reasonable time to address the issue before public disclosure.
